# homebrew-l0-git

Homebrew tap for [l0-git](https://github.com/fabriziosalmi/l0-git).

```sh
brew install fabriziosalmi/l0-git/l0-git
```

This installs the `lgit` binary from the GitHub release. On macOS the binary is
signed with a Developer ID and notarized.

The formula is updated by the l0-git release workflow on every stable tag.
